# Glossaire des annonces — allemand / anglais → français

Les annonces zurichoises sont majoritairement en allemand. Ces vingt termes
suffisent à décoder 90 % d'une annonce.

## Le vocabulaire qui change la décision

| Allemand | Anglais | Français | Pourquoi c'est important |
|---|---|---|---|
| **Untermiete** / **Zwischenmiete** | sublet | **sous-location** | ✅ Le mot-clé à chercher pour 6 mois |
| **befristet** | fixed-term | **à durée déterminée** | ✅ Compatible avec un stage |
| **unbefristet** | open-ended | à durée indéterminée | Bail long, résiliation trimestrielle |
| **Nachmieter gesucht** | successor tenant wanted | **reprise de bail** | ✅ Entrée rapide, souvent sans dossier lourd |
| **möbliert** | furnished | **meublé** | ✅ Quasi indispensable pour 6 mois |
| **ab sofort** | available now | **libre immédiatement** | |
| **per 1. Oktober** | from 1 October | à partir du 1er octobre | |
| **Kaution** / **Depot** | deposit | **caution** | Légalement max 3 loyers, sur compte bloqué |
| **Nebenkosten (NK)** | utilities / service charges | **charges** | |
| **inkl. NK** / **warm** | incl. utilities | **charges comprises** | |
| **exkl. NK** / **kalt** | excl. utilities | hors charges | Ajouter CHF 100–250/mois |

## Suisse allemand

Les annonces entre particuliers glissent souvent vers le dialecte : *Wohnig*
(Wohnung), *gsuecht* (gesucht, recherché), *Znüni*, *Putzete* (ménage), *Velo*
(vélo), *Hoi* / *Grüezi* (salut / bonjour). Le pipeline les repère et étiquette
l'annonce 🇨🇭 plutôt que 🇩🇪 — c'est presque toujours le signe d'un particulier,
pas d'une régie.
